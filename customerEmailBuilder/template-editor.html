How to get a token (one time per computer)
  1. On GitHub, go to Settings → Developer settings → Personal access tokens → Fine-grained tokens and choose Generate new token.
  2. Repository access: Only select repositories → tomlucero/miniApps.
  3. Permissions: Contents → Read and write. Nothing else is needed.
  4. Pick an expiration, generate it, and paste it here. It is stored only in this browser.
